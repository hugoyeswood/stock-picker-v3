## 🧠 大师逻辑打分（利弗莫尔 / 欧奈尔）
| 维度 | 规则 | 分值 |
|---|---|---|
| 今日强势 | 涨跌幅 ≥2% → +2；0~2% → +1 | 趋势启动 |
| 放量确认 | 量比 ≥1.5 → +2；≥1.0 → +1 | 量价齐升 |
| 换手活跃 | 3~15% → +2；>15% → **-1**（防过热） | 活跃度 |
| 站上5日线 | 现价 > MA5 → +1；否则 -1（K线维度） | 上升趋势确认 |
| 估值 | PE 0~80 → +1 | 估值适中 |

**分级**：`🏆最优(≥7分)` · `⭐优选(≥5分)` · `关注(<5分)` · 分数<3淘汰
**买卖点**：止盈=现价×1.12 · 止损=max(现价×0.94, 近20日最低×0.99) · 涨停峰值=创业板×1.2/主板×1.1 · 买入区间=MA5与现价之间

## 🚀 极简部署（保姆级）

### 方式A：GitHub Actions 自动部署（推荐，无需本地环境）
1. 把本仓库 **Fork** 到你自己的 GitHub 账号（右上角 Fork）。
2. 进入你的 Fork 仓库 → **Settings → Pages**：
   - Source 选 **GitHub Actions**（不用选分支，Actions 自动发布）。
3. 打开 **Actions** 标签 → 找到「每日自动选股-V3大师版」→ **Run workflow** 手动跑一次。
4. 等几分钟，绿色对勾即部署成功。
5. 访问你的专属链接：`https://<你的用户名>.github.io/stock-picker-v3/`
   （用户名=你的GitHub账号名，注意仓库名必须叫 stock-picker-v3）

### 方式B：本地运行（想自己看效果）
```bash
pip install akshare pandas
python build_site.py        # 生成 index.html + data.json + candidates.json
```
然后用任意静态服务器打开 index.html 即可（如 `python -m http.server 8000`）。
